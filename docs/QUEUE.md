## รอบ 0.61 (ต่อจาก 0.60)

### จากคำตอบของ Poom ต่อรายงาน 0.60
- ⬜ หน้าเพิ่มไฟล์: ตัวเลข "เลือกแล้ว N" ต้องล้างทุกครั้งที่เปิดหน้าใหม่ (บั๊ก "เลือกแล้ว 4" แต่ "เพิ่ม 0 เพลง")
- ⬜ ซ้ำทั้งรายการ + สุ่ม: สุ่มลำดับใหม่ทุกรอบ ไม่ใช้ลำดับเดิม
- ⬜ audio focus ในทาง VLC: จาร์วิสพูดระหว่างเพลง/วิดีโอที่เล่นผ่าน VLC ต้องหรี่หรือพักเหมือนทาง Media3
- ⬜ แถบสมดุลซ้าย-ขวา: ขึ้นสถานะใช้ไม่ได้เมื่อเล่นไฟล์ VLC ห้ามเลื่อนได้แต่ไม่มีผล
- ⬜ ยืนยันว่า gettext ถูกลิงก์เข้า libvlc.so จริงไหม และ license อะไร
- ⬜ ทดสอบ Hey Jarvis ซ้ำบน build สุดท้าย
- ✅ ลบเพลงทีละเพลงออกจากรายการ: ไม่ต้องยืนยันตัวตน (Poom) — ไม่ต้องแก้โค้ด
- ✅ ข้ามจุดเสียของ VCD: ใช้แบบเดิมได้ (Poom)
- ✅ playlist ทดสอบที่เหลือ: Poom ลบเองบนเครื่อง

### คิวหลัก
1. ⬜ บั๊กสุ่ม: เพลงจบแล้วไม่ต่อ — แก้แล้วใน 0.60 ทดสอบซ้ำทุกคู่ สุ่ม × โหมดซ้ำ และเพิ่มเพลงระหว่างเล่น (หลังเปลี่ยนเป็นสุ่มใหม่ทุกรอบ)
2. ⬜ ตรวจว่ารอบ 0.57–0.60 แก้ `server/` หรือไม่ ถ้าแก้ ใส่คำสั่ง deploy ในรายงานหัวข้อ ค.
3. ⬜ ปฏิทิน: อ่านนัด และเพิ่มนัดด้วยเสียง
4. ⬜ วัดผลการเก็บเสียงก่อนคำปลุก (สงสัยเสียงบี๊บทับพยางค์แรก, DESIGN ข้อ 11ก)
